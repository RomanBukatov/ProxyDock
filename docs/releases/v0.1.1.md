## Русский

- Команда «Завершить» вызывает штатный пункт выхода в меню «Файл» открытого окна Codex Desktop. Claude Desktop получает уведомление, которое запускает его процедуру выхода.
- Принудительное завершение повторно проверяет дерево выбранного экземпляра. При отказе Windows показывает PID и код Win32. Перезапуск ждёт завершения старого экземпляра перед применением нового прокси.
- Карточки MSIX-приложений сохраняют привязку к пакету при повторной проверке. Системный RuntimeBroker больше не удерживает карточку Claude в состоянии «В фоне». Отдельные службы Claude и ChatGPT продолжают работать.
- Установленная и portable-версии 0.1.0 обновляются через «Настройки → Обновления». Для standalone скачайте новый EXE. Профили и настройки сохраняются.

## English

- Graceful exit uses the Quit command in an open Codex Desktop window's File menu. Claude Desktop receives the Windows notification that starts its own quit procedure.
- Force quit rechecks the selected instance's process tree. If Windows denies termination, ProxyDock shows the PID and Win32 error code. Restart waits for the previous instance to exit before applying the selected proxy.
- MSIX app cards retain package identity across process checks. The Windows RuntimeBroker no longer keeps the Claude card in the background state. The separate Claude and ChatGPT services continue running.
- Installer and portable users on v0.1.0 can update through Settings → Updates. For the standalone edition, download the new executable. Profiles and settings carry over.
